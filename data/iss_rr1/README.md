# NASA RR-1 · ISS Environment

The [cabin dataset](cabina.csv) contains **12,087 readings** from September 20 to November 1, 2014, in GMT controller time. The columns distinguish between the ISS environment and the ground control environment. The observed CO₂ levels on the ISS range from 1,862 to 4,667 ppm. Most intervals last five minutes, while the longest lasts 33 minutes. Temperature in °C and relative humidity in % are also preserved. [NASA RR-1 Mission Dashboard](https://visualization.osdr.nasa.gov/eda/dashboard_RR-1)

The [ambient radiation dataset](radiacion_ambiental.csv) contains **39 daily records** from September 21 to October 29, 2014. According to the viewer's legend, it includes absorbed dose rates from Galactic Cosmic Rays (GCR), the South Atlantic Anomaly (SAA), and the total, expressed in mGy/day. The original dates are preserved, while cumulative values are omitted from the derived table. [EDA Radiation Legend](https://visualization.osdr.nasa.gov/eda/static/js/radiation_plots.js)

In the interface, these datasets can be represented as historical **environmental** time series. Expressing CO₂ as partial pressure would require synchronized total pressure measurements. The facility's mGy/day values and the personal dosimeter's μSv/h values represent different physical quantities. There is also no crew biometrics paired with these records. RR-1 (2014) and the DONKI event (2024) correspond to independent time periods.

**Reproduction and Attribution.** The script saves the JSON object published by the viewer and extracts the relevant columns without resampling or interpolation. From the project root, run `.\.venv\Scripts\python.exe ml\preparar_entorno.py`. With the original dataset and its verification record available, it works offline.
